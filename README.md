# propmpts

**Public AI Prompts & Tools**

This repository contains a collection of advanced system prompts designed for professional development, business strategy, and personal efficiency.

🚀** How to Use**

You can utilize these prompts in two primary ways:

1. Direct Usage (Copy & Paste)

Simply open the desired file, copy the raw text, and paste it directly into the chat window of any major LLM.

2. Build Your Own Agent

You can use these prompts as the core System Instruction to create persistent, personalized AI assistants like:

Gemini Gems: Create a new Gem and paste the prompt into the "Instructions" field.
OpenAI Custom GPTs: Use the prompt in the "Configure" tab.
Claude Projects: Add the prompt to the Project custom instructions.
